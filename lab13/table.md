| Этап | Участник | Действие | Математическая формула |
|------|----------|----------|------------------------|
| **1. Инициализация сервера** | Сервер | Генерация ключей RSA | `p, q ← простые`<br>`N = p * q`<br>`φ = (p-1)*(q-1)`<br>`D: 1 < D < φ, НОД(D,φ)=1`<br>`C = D⁻¹ mod φ` |
| **2. Подготовка бюллетеня** | Клиент | Кодирование выбора | `n = (случайные_32_бита << 2) \| v`<br>`v ∈ {1,2,3}` |
| **3. Хеширование** | Клиент | Вычисление хеша | `h = SHA3-256(n) mod N` |
| **4. Ослепление** | Клиент | Выбор ослепляющего фактора | `r ← случайное, 1 < r < N`<br>`НОД(r, N) = 1` |
| | Клиент | Вычисление ослепленного хеша | `h' = h * rᴰ mod N` |
| **5. Запрос подписи** | Клиент → Сервер | Отправка ослепленного хеша | `(voter_id, h')` |
| **6. Проверка избирателя** | Сервер | Проверка на повторное голосование | `voter_id ∉ voters_who_received_ballots` |
| **7. Подпись ослепленного хеша** | Сервер | Подпись закрытым ключом | `s' = (h')ᶜ mod N` |
| **8. Возврат подписи** | Сервер → Клиент | Отправка подписи | `s'` |
| **9. Снятие ослепления** | Клиент | Вычисление обратного элемента | `r⁻¹ mod N` |
| | Клиент | Получение конечной подписи | `s = s' * r⁻¹ mod N` |
| **10. Отправка бюллетеня** | Клиент → Сервер | Анонимная отправка | `(n, s)` |
| **11. Проверка подписи** | Сервер | Перевычисление хеша | `h = SHA3-256(n) mod N` |
| | Сервер | Проверка подписи | `sᴰ mod N ?= h` |
| **12. Принятие голоса** | Сервер | Добавление в урну | `ballot_box.append(n)` |
| **13. Подсчет результатов** | Сервер | Извлечение выбора | `v = n & 0b11` |
| | Сервер | Агрегация голосов | `results[v]++` |

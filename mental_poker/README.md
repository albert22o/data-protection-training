# Mental Poker - Texas Hold'em

Реализация протокола "Ментальный покер" с графическим интерфейсом и сетевым взаимодействием.

## Особенности

- ✅ Криптографически безопасная раздача карт
- ✅ Графический интерфейс на Tkinter
- ✅ Клиент-серверная архитектура
- ✅ Поддержка нескольких игроков
- ✅ Чат между игроками
- ✅ Реализация правил Техасского Холдема

## Запуск

### Требования
- Python 3.8+
- Стандартные библиотеки Python (socket, threading, tkinter, etc.)

### Запуск сервера
```bash
# Вариант 1: Через bat файл (Windows)
start_server.bat

# Вариант 2: Через Python
python server/main.py

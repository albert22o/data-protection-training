# **Документация к программе sign_elgamal.cpp**

## Что делает программа

Программа реализует **алгоритм электронной цифровой подписи (ЭЦП)** на основе криптосистемы **Эль-Гамаля**.

Подпись используется не для шифрования данных, а для **проверки подлинности** отправителя и **целостности** передаваемого сообщения.

Участвуют два участника:

* **Боб** — владелец ключей.
  Он создаёт **публичный** и **приватный** ключи, подписывает сообщения.
* **Алиса** — получатель.
  Она проверяет, что подпись действительно создана Бобом и сообщение не изменено.

---

### Основная идея ЭЦП Эль-Гамаля

> Пусть даны:
>
> * большое простое число $p$;
> * первообразный корень $g$ по модулю $p$;
> * закрытый ключ $x$ — случайное число $1 < x < p-1$;
> * открытый ключ $y = g^x \bmod p$.
>
> Тогда подпись и проверка выполняются по формулам:
>
> * **Создание подписи:**
>
>   * выбрать случайное $k$, где $1 < k < p-1$, $\gcd(k, p-1) = 1$;
>   * вычислить $r = g^k \bmod p$;
>   * найти $k^{-1} \bmod (p-1)$;
>   * вычислить
>     $s = k^{-1} \cdot (h - x \cdot r) \bmod (p-1)$,
>     где $h$ — хеш файла.
> * **Проверка подписи:**
>   подпись $(r, s)$ верна, если выполняется равенство:
>
>   $y^r \cdot r^s \equiv g^h \pmod{p}$.

## 1. Генерация ключей — `cmd_genkeys()`

**Назначение:**
Создать параметры $p$, $g$, а также пару ключей $(x, y)$ и сохранить их в файл.

---

### Алгоритм пошагово

1. **Генерация простого числа `p`:**

   ```cpp
   ll p = generate_prime(min_prime, max_prime);
   ```

   * Используется функция `generate_prime()` из `cryptography.cpp`.
   * Проверка простоты — вероятностным методом Миллера–Рабина.

2. **Поиск первообразного корня `g`:**

   ```cpp
   ll g = find_generator(p);
   ```

   * Используется функция `find_generator()` из `cryptography.cpp`.
   * Значение `g` — минимальное число, порождающее все ненулевые вычеты по модулю `p`.

3. **Выбор секретного ключа `x`:**

   ```cpp
   std::uniform_int_distribution<ll> dist(2, p - 2);
   ll x = dist(rng);
   ```

   * $x$ выбирается случайно в диапазоне $[2, p-2]$.

4. **Вычисление открытого ключа `y`:**

   ```cpp
   ll y = mod_pow(g, x, p);
   ```

   * `mod_pow()` — быстрое возведение в степень по модулю.
   * $y = g^x \bmod p$.

5. **Сохранение ключей в файл:**

   ```
   p
   g
   y
   x
   ```

   * $p, g, y$ — публичные параметры.
   * $x$ — приватный ключ.

---

## 2. Создание подписи — `cmd_sign()`

**Назначение:**
Создать цифровую подпись файла с использованием приватного ключа.

---

### Алгоритм

1. **Вычисление хеша файла:**

   ```cpp
   auto digest = file_sha256(infile);
   ```

   * Применяется алгоритм **SHA-256** (через `<openssl/sha.h>`).
   * Полученный 256-битный хеш преобразуется в число `h` из диапазона `[1, p−1]`.

   ```cpp
   ll h = digest_to_h(digest, p);
   ```

2. **Выбор случайного параметра `k`:**

   ```cpp
   ll k = random in [2, p−2], gcd(k, p−1) == 1;
   ```

   * Требуется, чтобы `k` имело обратный элемент по модулю `(p−1)`.

3. **Вычисление параметров подписи:**

   ```cpp
   ll r = mod_pow(g, k, p);
   ll k_inv = modinv_via_egcd(k, p - 1);
   ll s = (k_inv * (h - x * r)) % (p - 1);
   ```

   * Здесь `modinv_via_egcd()` — нахождение обратного элемента с помощью расширенного алгоритма Евклида.

4. **Сохранение подписи в файл:**

   Формат файла `.sig`:

   ```
   ELGS        (4 байта — сигнатура формата)
   p           (8 байт)
   r           (8 байт)
   s           (8 байт)
   ```

   ```cpp
   out.write("ELGS", 4);
   write_le64(out, p);
   write_le64(out, r);
   write_le64(out, s);
   ```

5. **Результат:**

   Подпись записывается в отдельный файл `<имя>.sig`.

---

## 3. Проверка подписи — `cmd_verify()`

**Назначение:**
Проверить подлинность подписи с использованием открытого ключа.

---

### Алгоритм

1. **Чтение подписи:**

   ```cpp
   auto [p, r, s] = read_sigfile(sigfile);
   ```

   * Проверяется сигнатура `"ELGS"`.
   * Считываются параметры `p`, `r`, `s`.

2. **Чтение ключа:**

   ```cpp
   auto [p_key, g, y, x] = load_keyfile(keyfile);
   ```

   * Проверяется, что `p_key` совпадает с `p` из подписи.

3. **Вычисление хеша исходного файла:**

   ```cpp
   auto digest = file_sha256(infile);
   ll h = digest_to_h(digest, p);
   ```

4. **Проверка равенства:**

   ```cpp
   ll left = (mod_pow(y, r, p) * mod_pow(r, s, p)) % p;
   ll right = mod_pow(g, h, p);
   ```

   Если `left == right`, подпись считается корректной.

5. **Результат:**

   ```
   Signature is VALID
   ```

   или

   ```
   Signature is INVALID
   ```

## 4. Структура ключевых функций

| Функция             | Назначение                             |
| ------------------- | -------------------------------------- |
| `generate_prime()`  | Генерация простого числа               |
| `find_generator()`  | Поиск первообразного корня по модулю p |
| `egcd()`            | Расширенный алгоритм Евклида           |
| `modinv_via_egcd()` | Обратный элемент по модулю             |
| `mod_pow()`         | Быстрое возведение в степень по модулю |
| `file_sha256()`     | Вычисление SHA-256 хеша                |
| `digest_to_h()`     | Преобразование хеша в число `h`        |
| `cmd_sign()`        | Формирование цифровой подписи          |
| `cmd_verify()`      | Проверка подписи                       |

## 5. Пример взаимодействия

| Этап | Участник | Действие                                | Формула          |
| ---- | -------- | --------------------------------------- | ---------------- |
| 1    | Боб      | Генерирует параметры `p`, `g`, `x`, `y` | $y=g^x\bmod p$   |
| 2    | Боб      | Вычисляет хеш файла $h$                 | SHA-256          |
| 3    | Боб      | Выбирает случайное $k$                  | $\gcd(k, p−1)=1$ |
| 4    | Боб      | Вычисляет $r=g^k\bmod p$                | —                |
| 5    | Боб      | Вычисляет $s=k^{-1}(h−x⋅r)\bmod(p−1)$   | cmd_sign         |
| 6    | Алиса    | Проверяет $y^r r^s \stackrel{?}{=} g^h$ | cmd_verify       |

## 6. Основные принципы подписи Эль-Гамаля

1. **Сложность подделки:**
   Для вычисления $x$ по $y=g^x\bmod p$ необходимо решить **дискретное логарифмирование**, что вычислительно невозможно при больших $p$.

2. **Проверяемость:**
   Любой, зная публичные параметры $(p,g,y)$, может убедиться, что подпись создана именно владельцем $x$.

3. **Целостность:**
   Изменение хотя бы одного байта файла изменяет $h$, и равенство при проверке не выполнится.

4. **Неотказуемость:**
   Только владелец приватного ключа $x$ может создать корректную пару $(r,s)$.

## 7. Пример работы программы

Из корневой директории:
```bash
# компиляция
g++ src/sign_elgamal.cpp -Ilib -Lbuild -lcryptography -o build/sign_elgamal -std=c++17 -Wall -O2 -lcrypto
```

Из директории `build/`:
```bash
# сгенерировать ключи
./sign_elgamal genkeys ../files/keys.txt 1000 5000

# подписать файл
./sign_elgamal sign ../files/text.txt ../files/text.sig ../files/keys.txt

# проверить подпись
./sign_elgamal verify ../files/text.txt ../files/text.sig ../files/keys.txt
```

**Вывод:**

```
Generated ElGamal params: p=3061 g=6 y=2439 x=796
signature written to ../files/text.sig
Signature is VALID
```

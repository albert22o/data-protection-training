# **Документация к программе `sign_gost.cpp`**

## Что делает программа

Программа реализует **алгоритм электронной цифровой подписи (ЭЦП)**
на основе отечественного криптографического стандарта **ГОСТ Р 34.10–94**.

В отличие от шифрования, где цель — скрыть содержание сообщения,
подпись служит для **проверки подлинности** и **целостности данных**.

В системе участвуют два участника:

* **Боб** — владелец ключей.
  Он создаёт **открытый** и **закрытый** ключи, подписывает сообщения.
* **Алиса** — получатель.
  Она проверяет, что подпись действительно создана Бобом и сообщение не изменено.

---

### Основная идея ГОСТ Р 34.10–94

> Подпись строится в **мультипликативной группе по модулю p**, где:
>
> * `p` и `q` — простые числа, связанные соотношением
>   $p = b \cdot q + 1 $;
> * `a` — элемент, порождающий подгруппу порядка `q` в $\mathbb{Z}_p^*$;
> * `x` — секретный ключ;
> * `y = a^x mod p` — открытый ключ.

---

### Формулы подписи:

1. **Создание подписи:**

   $r = (a^k \bmod p) \bmod q$
   
   $s = (k \cdot h + x \cdot r) \bmod q$
   

   где:

   * `h` — хеш сообщения (по ГОСТу: SHA-256 от файла, приведённый по модулю `q`);
   * `k` — случайное число из диапазона `[1, q−1]`.

2. **Проверка подписи:**
   
   $v = h^{-1} \bmod q$

   $z_1 = s \cdot v \bmod q,\quad z_2 = (q - r) \cdot v \bmod q$
   
   $u = ((a^{z_1} \cdot y^{z_2}) \bmod p) \bmod q$
   
   Подпись считается **действительной**, если (u = r).

---

## 1. Генерация параметров — `cmd_genparams()`

**Назначение:**
Создать параметры `p`, `q`, `a`, удовлетворяющие требованиям стандарта.

---

### Алгоритм пошагово

1. **Генерация простого числа `q`:**

   ```cpp
   ll q = generate_prime_bits_mt(bits_q, rng);
   ```

   * Используется вероятностный тест Миллера–Рабина (`is_probably_prime()`).
   * Размер `q` задаётся в битах (по умолчанию 16 бит).

2. **Поиск простого числа `p = b*q + 1`:**

   Программа перебирает множители `b`, пока не найдёт простое `p`:

   ```cpp
   for (b = 2; ; ++b) {
       p = b*q + 1;
       if (is_probably_prime(p)) break;
   }
   ```

   Условие $p = b*q + 1$ гарантирует существование подгруппы порядка `q`.

3. **Поиск генератора `a`:**

   Для случайного `g` из `[2, p−2]` вычисляется: $a = g^b \bmod p$ и проверяется, что $a^q \bmod p = 1$ и $a > 1$.

4. **Сохранение параметров:**

   ```
   p
   q
   a
   ```

   Пример вывода:

   ```
   Generated params: p=1074161351 q=60859 a=1025709518 (b=17650)
   ```

---

## 2. Генерация ключей — `cmd_genkeys()`

**Назначение:**
Создать закрытый и открытый ключи на основе ранее сгенерированных параметров.

---

### Алгоритм

1. **Загрузка параметров `p, q, a`.**

2. **Выбор секретного ключа `x`:**

   ```cpp
   uniform_int_distribution<long long> distx(1, q-1);
   ll x = distx(rng);
   ```

3. **Вычисление открытого ключа:**

   $y = a^x \bmod p$

4. **Сохранение в файл ключей:**

   ```
   p
   q
   a
   x
   y
   ```

   Где:

   * `x` — секретный ключ (хранится только у владельца);
   * `y` — открытый ключ, используется при проверке подписи.

---

## 3. Создание подписи — `cmd_sign()`

**Назначение:**
Вычислить цифровую подпись для указанного файла.

---

### Алгоритм

1. **Вычисление хеша файла:**

   ```cpp
   auto dg = file_sha256(infile);
   ll h = digest % q;
   if (h == 0) h = 1;
   ```

   * Используется **SHA-256** (через `<openssl/sha.h>`).
   * Хеш приводится по модулю `q`, чтобы соответствовать размеру параметров ГОСТа.

2. **Выбор случайного `k ∈ [1, q−1]`.**

3. **Вычисление параметров подписи:**

   ```cpp
   r = (a^k mod p) % q;
   s = (k*h + x*r) % q;
   ```

4. **Сохранение подписи:**

   Формат файла `text.sig`:

   ```
   p q a y r s
   ```

   Пример:

   ```
   1074274511 48023 668083937 1036483367 39020 30367
   ```

5. **Результат:**

   ```
   Signature written to text.sig
   ```

---

## 4. Проверка подписи — `cmd_verify()`

**Назначение:**
Проверить корректность подписи файла по открытому ключу.

---

### Алгоритм

1. **Загрузка параметров `p, q, a, y` из файла подписи.**

2. **Вычисление хеша файла (тот же SHA-256).**

3. **Проверка условий корректности:**

   ```
   0 < r < q, 0 < s < q
   ```

4. **Вычисление промежуточных значений:**

   ```cpp
   v = modinv(h, q);
   z1 = (s * v) % q;
   z2 = ((q - r) * v) % q;
   ```

5. **Проверка подписи:**

   $u = ((a^{z_1} \cdot y^{z_2}) \bmod p) \bmod q$

   Если $u = r$ → `Signature is VALID`, иначе → `INVALID`.

## 5. Структура ключевых функций

| Функция                    | Назначение                                      |
| -------------------------- | ----------------------------------------------- |
| `generate_prime_bits_mt()` | Генерация простого числа заданной битовой длины |
| `is_probably_prime()`      | Проверка числа на простоту (Миллер–Рабин)       |
| `mod_pow()`                | Быстрое возведение в степень по модулю          |
| `egcd(), modinv_safe()`    | Расширенный алгоритм Евклида и обратный элемент |
| `file_sha256()`            | Вычисление SHA-256 хеша файла                   |
| `cmd_genparams()`          | Генерация параметров `p, q, a`                  |
| `cmd_genkeys()`            | Создание ключей `x, y`                          |
| `cmd_sign()`               | Формирование цифровой подписи                   |
| `cmd_verify()`             | Проверка подписи                                |

## 6. Пример взаимодействия

| Этап | Участник | Действие                       | Формула                                    |
| ---- | -------- | ------------------------------ | ------------------------------------------ |
| 1    | Боб      | Генерирует параметры `p, q, a` | $p=bq+1$                                   |
| 2    | Боб      | Создаёт ключи `x, y=a^x mod p` | cmd_genkeys                                |
| 3    | Боб      | Вычисляет хеш файла `h`        | SHA-256                                    |
| 4    | Боб      | Создаёт подпись `(r, s)`       | $r=(a^k mod p) mod q$, $s=(k·h+x·r) mod q$ |
| 5    | Алиса    | Проверяет подпись              | $u=((a^{z1}·y^{z2}) mod p) mod q$          |
| 6    | Алиса    | Сравнивает `u` и `r`           | если равны → подпись верна                 |

---

## 7. Основные свойства ГОСТ-подписи

1. **Односторонность:**
   По открытому ключу `y` невозможно вычислить закрытый `x`.

2. **Проверяемость:**
   Любой, зная `y`, `a`, `p`, `q`, может проверить подлинность подписи.

3. **Целостность:**
   Изменение даже одного байта файла изменяет `h` → подпись становится недействительной.

4. **Неотказуемость:**
   Только владелец закрытого ключа `x` может сформировать корректную пару `(r, s)`.

---

## 8. Пример работы программы

```bash
# 1. Генерация параметров
./sign_gost genparams ../files/params.txt 31 16

# 2. Генерация ключей
./sign_gost genkeys ../files/alice.key ../files/params.txt

# 3. Подпись файла
./sign_gost sign ../files/text.txt ../files/text.sig ../files/alice.key

# 4. Проверка подписи
./sign_gost verify ../files/text.txt ../files/text.sig ../files/alice.key
```

**Вывод:**

```
Signature written to ../files/text.sig
Signature is VALID
```
